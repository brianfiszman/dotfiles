# Agent work log

This file is a pointer, not the log itself. Logs rotate by month so no single
file becomes an unscannable transcript.

- **Current month:** [`docs/agent-log/2026-11.md`](docs/agent-log/2026-11.md)
- **All monthly files:** [`docs/agent-log/`](docs/agent-log/)

Append concise entries to the current monthly file for meaningful discoveries,
decisions, failures, mitigations, and handoffs. Keep detailed implementation and
review discussion in its canonical issue, PR, commit, or CI run; link it rather
than copying it. Corrections are new entries that link to the corrected record.

Rotation procedure: see
[`.agents/skills/agent-memory-hygiene/SKILL.md`](.agents/skills/agent-memory-hygiene/SKILL.md).
